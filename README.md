# pairwise-audio-mixer

我们的游戏音频中间件在复杂场景里会爆音：总线 send 到 reverb 后没有按缓冲块做延迟补偿，鼓点和混响对不上；侧链压缩只在单条 bus 上生效，music 总线被 ducking 时语音和 UI 音效不受影响；不同采样率的子混音直接相加，低频出现拍频；3D 声源距离衰减用线性插值，远近切换时音量跳变；并发声源超过上限时直接丢弃最新请求，Boss 技能音效经常没声；卷积混响的 tail 没有按块对齐，切换场景时尾音被硬切；bus 图里有环时递归遍历直接栈溢出；暂停时 DSP 时钟还在走，恢复后所有延迟线错位。audio/mixer.py 是核心，tests/test_mixer.py 15个红。要修的是：按缓冲块做延迟补偿和 tail 对齐；侧链按 bus 图向下游传播；重采样后再混音；距离衰减按对数曲线并做滞回；声源上限按优先级和距离淘汰；bus 图做拓扑排序并检测环；暂停/恢复重置 DSP 时钟和延迟线。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
